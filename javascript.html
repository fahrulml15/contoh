JavaScript

JavaScript adalah bahasa pemrograman tingkat tinggi dan dinamis. JavaScript populer di internet dan dapat bekerja di sebagian besar penjelajah web populer seperti Google Chrome, Internet Explorer (Edge), Mozilla Firefox, Netscape dan Opera. Kode JavaScript dapat disisipkan dalam halaman web menggunakan tag <script>.

Sejarah JavaScript dimulai pada tahun 1995 ketika Brendan Eich, seorang programmer di Netscape Communications, ditugaskan untuk membuat bahasa scripting ringan yang bisa berjalan di browser Netscape Navigator. Bahasa ini pada awalnya diberi nama Mocha, kemudian diubah menjadi LiveScript, dan akhirnya menjadi JavaScript untuk memanfaatkan popularitas bahasa pemrograman Java pada saat itu, meskipun keduanya memiliki desain dan konsep yang sangat berbeda.

Fungsi utama JavaScript adalah untuk membuat halaman web menjadi interaktif. Jika HTML digunakan untuk menyusun struktur halaman dan CSS untuk mendesain tampilannya, maka JavaScript adalah bagian yang memungkinkan halaman tersebut merespons tindakan pengguna. Beberapa contoh penerapan JavaScript yang sering ditemui termasuk validasi formulir, efek animasi dinamis, pop-up peringatan, dan pembaruan konten halaman tanpa harus memuat ulang (reload) seluruh situs.

Seiring dengan perkembangannya, JavaScript tidak lagi hanya digunakan di sisi klien (browser). Dengan hadirnya lingkungan runtime seperti Node.js, JavaScript kini juga dapat digunakan untuk pengembangan aplikasi sisi server (backend), pembuatan aplikasi desktop, pengembangan game, hingga pembuatan aplikasi seluler.

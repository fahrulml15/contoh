Pengantar Pemrograman Web Statis

Pemrograman web statis adalah pembuatan halaman web yang kontennya tetap dan sama untuk semua pengguna, dikirimkan langsung dari server ke peramban (browser) tanpa pemrosesan server-side. Konten situs ini hanya akan berubah jika pengembang mengubah kode file utamanya secara manual.

Sebuah website statis umumnya dibangun menggunakan tiga fondasi utama, yang juga dibahas secara khusus dalam menu web ini:

  • HTML: Bertindak sebagai kerangka kerja yang membentuk struktur dasar dan mendefinisikan konten.
  • CSS: Berperan sebagai desainer yang mempercantik tampilan, mengatur tata letak (layout), warna, dan tipografi.
  • JavaScript: Sebagai penggerak yang memberikan elemen interaktivitas dan fungsionalitas sisi klien.

Karakteristik Utama Web Statis:

  • Isi Tetap: Konten tidak bergantung pada interaksi database secara real-time.
  • Performa Cepat: Kecepatan akses yang ringan and instan karena dokumen HTML langsung di-load dari server.
  • Keamanan Tinggi: Risiko diretas sangat minim karena tidak memiliki database server yang aktif.
  • Penggunaan Ideal: Sangat cocok untuk situs web company profile, portofolio pribadi, dan landing page.
